# TOIRA 原型（GitHub Pages）

平板／手機用瀏覽器開啟即可，不必安裝。

**資料庫：** 階段一寫回大眾版，另加三張十業新卡，共 174 張（`judge_draft/phase1_writeback_refined/` 為原 166 張底稿）。網頁版 `tasksLibrary.json` 只保留評估欄位（不含 MAP／hazardControlMap）。

- 作業說明：依作業名稱的字面工作描述（單一段落），不是危害導讀。
- 防護標籤：`(工程改善)` / `(工程控制)` / `(行政管理)` / `(個人防護)`。畫面三欄仍是工程改善／行政管理／個人防護；職業病的 `(工程控制)` 歸在工程改善欄，文字保留工程控制。
- 核心重點：有 `核心重點: true` 的危害組會先展開並標示；其餘預設摺疊。

行業模板用 `industryMapping.json`（與 `給璞藝/industryMapping.json` 同一份；563 列、十業 451 列；未掛上的可從「資料庫查詢」加入）。

不要用過期的 `etool2資料匯出_tasksLibrary_2.0_0811_精簡_LLM.xlsx`（四段式描述）。若需 Excel，請由 slim.llm JSON 重匯。

## 使用

1. 倉庫 Settings → Pages → Build and deployment → Source: **Deploy from a branch**
2. Branch: `main` / folder: `/ (root)`
3. 網址：https://fefe9487.github.io/TOIRA_prototype/

流程：公司資料 → 選行業模板或自選製程 → 評估（可查詢全庫、自定義製程）→ PDF。

Excel 與 PDF 由瀏覽器直接產生；不再呼叫 AI 智慧轉換後端，也不傳送使用者填答至模型。Excel 使用本地隨附 JSZip，授權見 `vendor/JSZip-LICENSE.md`。

## 使用說明與手動評估（2026-10-11）

公司資料、行業選擇與評估頁共用 `usage-guide.js` 的使用說明圖卡，首次進入時顯示；同一分頁讀過本版後不重複彈出，可由頂端「使用說明」重新開啟。內容包含 AI 編製與專家審查流程、S／P 固定矩陣、使用限制及資料用途宣告。`faq.html` 提供 27 題固定問答、分類及關鍵字搜尋，法條全文預設收合。QA 查詢不呼叫 AI。

手動評估提供「調整理由／備註」，隨專案儲存並顯示於 PDF 報表預覽。相較系統現況估算調低風險時，會標示調整前後等級與責任提醒；自訂情境無系統基準，僅標示使用者手動評估。報表欄名使用「現有(已備有)防護措施」與「應採取之預防設施」。

原型保留嚴重度比較開關：關閉使用原 `severity`，開啟使用新增的 `ruleSeverity`。立即危險類型採 S5；職業病依可恢復性採 S4/S5。`DATA_VER` 維持 `20261005h` 以保留舊情境索引遷移；新增 `SEVERITY_POLICY_VER=20261011b` 供分級資料快取更新。作業庫、情境文字、索引與措施對照維持原樣。使用說明網址帶 `20261011d` 版本，樣式網址帶 `20261011b` 版本。

## 資料快取與更新

`Selection.html` 與 `New.html` 的 JSON 讀取使用一般 HTTP 快取（`cache: 'default'`），依伺服器的有效期限重用快取，過期時由瀏覽器重新驗證。評估頁不再強制略過快取，因此從行業選擇頁進入評估頁時可重用同一份作業資料。

兩頁共用相同的 `DATA_VER` 版本值。資料檔改版且需要立即取得新版時，同步更新兩頁的 `DATA_VER`；新的版本網址會重新讀取資料。初次開啟、清除快取或強制重新整理仍可能需要下載完整資料。

目前 `DATA_VER` 是 `20261005h`。情境對照的措施只存作業庫編號，句子在 `tasksLibrary.json` 的 `AvoidItems`。給資訊廠商的欄位說明見 `改版對照_20261002.md`。


20261005h 補齊職業病情境文字與歷史措施對照；6,193 條情境逐字對上作業庫。修復依據、重建限制及舊評估相容性見 [SCENARIO_TEXT_REPAIR.md](SCENARIO_TEXT_REPAIR.md)。


## AI 與資料用途（原型／正式上線政策）

AI 僅於公版作業資料建置階段輔助撰寫。正式可查詢內容須經專家審查。

使用者資料不提供 AI 讀取或再次訓練。正式平台規劃保留供匿名化之描述性分析使用，但本靜態原型尚未啟用集中蒐集與匿名分析。上線前須落實去識別、保存期間、存取權限及完整告知，不可將「瀏覽器保存」直接視為匿名化。
